# 桌面「印章识别」对接说明

后端目录：`淮来学长/backend`（原桌面「印章识别」）  

能力：蓝方知章 / 黄圆行章、11 种叠盖盖法、四角数字；DeepSeek 视觉或本地 OpenCV。

## 为何适合接入淮来学长

| 对比 | 腾讯云 SealOCR | 桌面印章识别 |
|------|----------------|--------------|
| 盖法 | 通用印章，无 11 种业务盖法 | 与需求文档 4.5.2 一致 |
| 当量 | 需自行猜映射 | 可按 ZE/XE/DE 直接换算 |
| 四角编码 | 弱 | 专为内侧四角数字设计 |

OpenCV / DeepSeek **不能**放进微信小程序包内，需作为独立识别服务。

## 推荐：直接用 DeepSeek（已接入小程序）

与桌面项目 `deepseek_ocr.py` 相同：视觉模型 + 11 种盖法提示词。

```bash
# 项目根目录 .env（已在 .gitignore）
cp .env.example .env
# 填入：VITE_DEEPSEEK_API_KEY=sk-xxx
# 可从 ../backend/.env 的 DEEPSEEK_API_KEY 复制

cd frontend
npm run dev:h5 -- --host --port 5173
```

采集页识别顺序：**DeepSeek → 桌面 Flask → 腾讯云 → 模拟**。

配置：`src/config/deepseek.js`  
实现：`src/services/deepseekSeal.ts`  
提示词：`src/constants/deepseekSealPrompt.ts`

## 可选：Flask 服务（backend）

```bash
cd ../backend
source .venv/bin/activate
python app.py   # http://127.0.0.1:8765/
```

H5 代理：`/seal-api` → `8765`（`vite.config.ts`）。

## 代码落点

- `src/constants/sealMethods.ts`：11 种盖法与当量
- `src/services/deepseekSeal.ts`：DeepSeek 视觉识别
- `src/services/sealRecognize.ts`：Flask 服务映射
- `src/services/ocr.ts`：识别优先级
- `src/pages/scan/scan.vue`：展示盖法与引擎来源

## 上线注意

1. 正式环境勿把 DeepSeek Key 打进公开仓库；微信小程序建议走自有后端代理再调 DeepSeek
2. 若仍用 Flask，需 HTTPS 合法域名
3. `deepseek-flash` 需关闭 thinking，否则 content 可能为空（代码已处理）

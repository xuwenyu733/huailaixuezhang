# 印章叠盖识别

成长记录册「盖章处」识别：**蓝方知章** + **黄圆行章**，支持 11 种叠盖盖法，方章内侧四角填写数字。

## 结论

**可以实现。** 推荐「颜色分离 → 形状/聚类 → 盖法分类 → 四角 OCR」流水线。

## 启动（上传图片识别）

网页默认走 **DeepSeek 视觉 API**（按 `prompts/deepseek_seal_ocr.md` / Skill 规则出 JSON）。也可切「本地」OpenCV。

```bash
cd backend   # 即 淮来学长/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 配置密钥（二选一）
cp .env.example .env   # 编辑填入 DEEPSEEK_API_KEY=sk-xxx
# 或: export DEEPSEEK_API_KEY=sk-xxx

python app.py
```

浏览器打开：**http://127.0.0.1:8765/**

- 首页：上传图片 / 样页试跑 → DeepSeek 或本地识别
- 盖法演示：http://127.0.0.1:8765/demo

命令行识别：

```bash
python src/pipeline.py assets/sample_page.png --show
```

## 两种章

| 类型 | 外观 | 数字 |
|------|------|------|
| 知章 | 蓝色方章（花+手） | 写在**内侧四角**（斜线旁）；叠盖取整组内角 |
| 行章 | 黄色圆章 | 无四角数字 |

## 11 种盖法

1. 正向章（知章）  
2. 引导章（知章，旋转 180°）  
3. 改进章（知章）  
4. 知章二叠章  
5. 知章三叠章  
6. 行章  
7. 行章二叠章  
8. 行章三叠章  
9. 知行对章  
10. 知行对章二叠章  
11. 知行对章三叠章  

定义见 `src/seal_methods.py`。

## 当前能力

| 模块 | 状态 |
|------|------|
| 盖章处裁列 / 单元切分 | 可用 |
| 知章 / 行章检测与叠盖分组 | 可用 |
| 盖法粗分类（1–11） | 可用（数量 + 知章 0°/180° 模板） |
| 正向 / 引导 / 改进 | 模板匹配朝向后细分 |
| 四角数字 OCR | 偏弱：样页分辨率低、数字与斜线粘连；严判输出，错宁缺 |

## 落地建议

| 阶段 | 内容 |
|------|------|
| 已做 | 分色检测、单元切分、盖法粗分、朝向匹配、内角 ROI |
| 下一步 | 知章模板匹配区分正向/引导/改进 |
| 数字 | 更高清扫描 + 角点数字标注微调（推荐） |
| 表格 | 有清晰表格线时可加强线检测 |

叠盖不必完美抠开每一枚章：用**组级**特征（章数、相对布局、旋转）匹配盖法即可。

家长端 · 缺口原型

按需求文档第 4 章缺口优先级 1→5。手机框可点，未接接口。

01

注册验证码 + 孩子编辑 / 绑定班级

短信验证码注册；孩子编辑（性别/生日/入学）；绑定班级码弹窗。
02

虚拟盖章 · 11 盖法 + 近 7 日历史

正向/引导/改进/叠章/行章/对章全套选择与当量预览、历史列表。
03

报告 PDF 导出 + 全部评价

导出确认流；首页「查看全部」进入完整评价时间线。
04

海棠成长树 · 学期周视图

一学期按周列的家庭端编码表，单元格盖章状态。
05

激励目标下单 + 商城 PIN（可配置）

商品→加目标→达标确认下单；PIN 开/关示意（文档要、产品曾关）。
